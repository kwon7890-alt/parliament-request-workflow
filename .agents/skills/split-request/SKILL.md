# 자료요구서 문항 분리

## 언제 쓰는지

- `원문/`의 국회 자료요구서 PDF를 문항별 CSV로 만들 때 사용한다.
- 프로젝트 맨 위에 실행 가능한 `split.py`를 새로 만들거나 고칠 때 사용한다.
- 교체된 정답 `문항목록.csv`와 생성 결과를 대조할 때 사용한다.

## 순서

1. `처리지침.md` 제2장, 원문 PDF, 기존 `split.py`, 정답 문항목록이 있으면 모두 먼저 읽는다.
2. `pypdf`를 불러올 수 있는지 확인한다. 없으면 `pip install pypdf` 명령만 보여 주고 사용자가 허락한 뒤 설치한다.
3. 파이썬 표준 라이브러리와 `pypdf`만 사용하는 `split.py`를 프로젝트 맨 위에 만든다.
4. PDF의 첫 번째 비어 있지 않은 줄 `○○위원회 ○○ 의원실 자료요구서`에서 위원회와 의원을 추출한다.
5. `제출기한:` 뒤의 `YYYY. M. D.`를 `YYYY-MM-DD`로 바꾼다.
6. `수신:`, `담당 보좌관:`, `끝.`은 저장하지 않는다. 이름·전화번호·이메일을 문항 데이터에 넣지 않는다.
7. 줄 맨 앞의 `숫자.`는 새 문항으로, `가.`, `나.` 등은 앞 문항의 세부항목으로, `※`는 앞 문항의 비고로 분리한다. 그 밖의 줄은 바로 앞 항목에 공백 하나로 잇는다.
8. 교체된 정답 형식에 맞춰 여러 세부항목은 ` / `로 연결하고, 비고 앞의 `※`와 뒤 공백은 제거한다.
9. `data/문항목록.csv`를 UTF-8-SIG로 저장한다. 열 순서는 `파일명 | 위원회 | 의원 | 제출기한 | 문항번호 | 요구내용 | 세부항목 | 비고`로 고정한다.
10. 아래 확인 기준을 모두 검사한다. 하나라도 실패하면 원인을 고쳐 다시 실행한다.

## 확인 기준

- 파일별로 `파일명의 문항 수 | 뽑은 문항 수 | 마지막 번호 | 번호 연속 | 일치(O/X)` 표를 보여 준다.
- 파일명의 `_N문항.pdf`에서 읽은 수, 추출 행 수, 마지막 번호가 모두 같아야 한다.
- 문항번호는 1부터 마지막 번호까지 연속이어야 한다.
- `(파일명, 문항번호)` 중복, 빈 필수 열, 제외 대상 문구, 전화번호·이메일이 없어야 한다.
- 세부항목 또는 비고가 있는 문항 3개를 원문 PDF와 나란히 확인한다.
- 정답 문항목록이 있으면 행 수, 열 순서, 행 순서, 모든 셀을 문자열 그대로 비교하여 차이가 0건이어야 한다.
- 원문 PDF와 정답 문항목록의 수정 전후 해시가 같아야 한다.

## 끝나는 조건

- 모든 파일의 일치 값이 O다.
- 생성된 CSV가 UTF-8-SIG이며 지정한 8개 열과 순서를 갖는다.
- 정답 파일이 있으면 셀 차이가 0건이다.
- `split.py`, 생성 CSV, 원문 PDF, 검증 결과 MD를 클릭할 수 있게 보여 준다.

## 하지 말 것

- 원문 PDF나 정답 CSV를 수정하지 않는다.
- `data/`의 다른 파일을 수정하지 않는다.
- 정답 행을 코드에 직접 넣어 결과를 맞추지 않는다.
- 연락처나 담당자 개인정보를 저장하거나 화면에 노출하지 않는다.
- 일치가 X인데 결과를 완료로 보고하지 않는다.
