# 소관 과 배분규칙 보강

## 1. 언제 쓰는지

- `web/engine.js`의 소관 과 후보에서 오답이 발생해 배분기준표의 제외어·키워드·우선순위를 보강할 때 사용한다.
- 입력은 원본 배분기준표, 조직도 26개 과, 시험 40건, 접수대장 520건이다.

## 2. 순서

1. 틀린 문항을 같은 키워드 충돌, 일반어 우세, 제외어 누락 등 원인별로 묶는다.
2. 원인마다 제외어 추가·키워드 추가·우선순위 조정 중 한 가지 수정안을 제안하고 대상 과가 조직도 26개 과 안인지 확인한다.
3. 사용자가 고른 방법만 원본이 아닌 `rules_보강.csv` 사본에 반영한다.
4. 원본과 사본으로 시험 40건 및 접수대장 520건의 1순위 정확도와 새로 틀린 문항을 비교한다.
5. 바꾼 규칙, 전·후 결과, 새 오답을 `PROGRESS.md`에 기록한다.

## 3. 끝나는 조건

- 변경한 규칙 외의 행과 셀은 원본과 같아야 한다.
- 시험 40건의 1순위 정답이 30건 이상이고 기존 정답 중 새로 틀린 문항이 0건이어야 한다.
- 접수대장 520건의 전·후 정확도와 회귀 건수도 기록되어야 한다.

## 4. 하지 말 것

- 원본 `data/배분기준표_소관키워드_304건.csv`를 수정하지 않는다.
- 사용자가 고르지 않은 수정안을 반영하지 않는다.
- 조직도 26개 과 밖의 부서를 만들지 않는다.
- 정확도가 올라도 새 오답을 숨기거나 시험 정답을 규칙에 직접 복사하지 않는다.
