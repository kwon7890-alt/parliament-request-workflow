# 문제정의서: 국회 요구자료 대응 도우미 회사용 확장

> 버전: `02_company_scale`  
> 전제: 회사 자료 약 11GB, ZIP·최근 자료 포함 시 약 20GB  
> 성격: PoC와 분리된 후속 운영 설계

| 칸 | 내용 |
|---|---|
| ① 현재 업무 | 실제 회사 자료는 접수대장뿐 아니라 요구서 PDF, HWP/HWPX, DOCX, XLSX/CSV, HTML, TXT, ZIP, 회신 및 지침 자료가 여러 폴더에 누적된다. 국회 총괄 담당은 과거 유사 요구, 최신 지침, 조직도, 회신 현황을 찾아 배분·취합하며 현업 담당은 해당 과 문항에 회신한다. 자료량은 약 11GB이고 ZIP과 최근 자료까지 포함하면 약 20GB로 예상된다. |
| ② 문제 | 매 요청마다 20GB 전체를 직접 읽으면 느리고 중복·변경 파일을 반복 처리한다. ZIP 속 중복, 동일 문서의 여러 형식, 오래된 지침과 최신 지침이 섞이며, 사람 이름·전화·이메일·API 키 후보·네트워크·보안장비 정보가 포함될 수 있다. 실행파일과 스크립트를 실수로 실행할 위험도 있다. 파일 경로만으로는 문서 간 관계, 처리 이력, 권한, 검색 근거를 관리하기 어렵다. |
| ③ 목표 | 원본을 바꾸지 않고 11~20GB 자료를 한 번 조사한 뒤 국회 업무 자료, 다른 업무에서 공유할 자료, 목록만 남길 자료, 제외 자료로 분류한다. 색인 승인 자료는 변경분만 갱신하고 파일 해시로 중복을 식별한다. 지원 문서는 텍스트·표와 출처 위치를 추출해 키워드 검색과 필요한 조각의 의미 검색을 제공한다. 민감정보와 위험 파일을 자동 분류하고 사람이 승인한 자료만 검색·임베딩 대상으로 사용한다. 추천 결과는 출처 파일·페이지·문단과 함께 제시하며 최종 배분은 사람이 확정한다. |
| ④ 범위 | **만들 것:** 수집 대상 분류 기준, 원본 보관소, 파일 목록·해시·중복 관리, 안전한 ZIP 목록화, 텍스트·표 추출, 메타데이터 DB, 키워드 검색, 선택적 임베딩, 권한·감사·파기 이력, 민감정보 검토, 배분·회신·취합 화면 연계. **C1에서 결정할 것:** 예산 RAG 등 다른 업무와 공용 수집층을 쓸지 여부. **만들지 않을 것:** 답변 자동 작성, 결재·국회 제출, EXE/BAT/REG 실행, 20GB 전체 무조건 임베딩, 회사 자료의 외부 AI 전송, 원본 수정. |
| ⑤ 검증 기준 | 전체 조사 대상의 파일 수·용량·해시와 수집 분류를 기록하고, 국회 업무 무관 자료가 승인 없이 색인되지 않도록 한다. 같은 해시 중복 식별, 변경 파일만 재처리, 위험 파일 실행 0건, 위치를 아는 가상 민감정보(API 키·전화번호·이메일·IP) 탐지율 100%, 비승인 민감정보 임베딩 0건, 검색 결과 원문 출처 표시 100%, 변경·권한·파기 이력 누락 0건을 확인한다. 성능 기준은 회사 장비와 실제 파일 수를 측정한 뒤 확정하며 근거 없이 처리시간 숫자를 약속하지 않는다. 실제 회사 문항 표본의 1순위 배분 정확도는 75% 이상이어야 한다. |

## 핵심 과제

| 영역 | 해결해야 할 일 |
|---|---|
| 규모 | 전체 재스캔 대신 최초 수집 + 변경분 갱신 |
| 중복 | 경로·파일명과 별도로 해시 기반 동일 파일 식별 |
| 검색 | 키워드 검색을 기본으로 하고 의미 검색은 선별 자료에만 적용 |
| 출처 | 추천·검색 결과마다 원본 파일과 위치 제시 |
| 보안 | 민감정보 탐지·마스킹·승인·제외 이력 |
| 위험 파일 | 실행하지 않고 메타데이터와 해시만 기록 |
| 최신성 | 지침 시행일·작성일·수정일을 기록해 최신 기준을 우선 표시 |
| 운영 | 사용자·권한·변경·재처리·실패 이력 보존 |
| 수집 범위 | 국회 업무 자료만 기본 색인하고 설치파일·교육자료·과업지시서 등 무관 자료는 목록·해시만 남기거나 제외 |

## PoC와의 경계

`01_poc`의 화면 흐름과 상태 개념은 참고하되, 회사용은 별도 저장소와 데이터베이스를 사용한다. PoC의 `cases.json`을 20GB 운영 저장소로 확대하지 않는다. C1에서 국회 업무 자료의 분류 기준과 다른 업무와의 공용 수집층 사용 여부를 결정한다. 운영 전에는 보안 담당자와 자료 반입·권한·보존기간·파기 기준을 확정해야 한다.
