# 문제정의서: 국회 요구자료 대응 도우미 PoC

> 버전: `01_poc`  
> 목적: 교육용 자료로 배분 추천, 상태 관리, 취합·검사의 실현 가능성을 검증한다.  
> 범위 밖: 답변 작성, 결재, 국회 제출, 실제 내부시스템 연계

| 칸 | 내용 |
|---|---|
| ① 현재 업무 | A부 국회 총괄 담당은 요구서를 접수해 문항 단위로 정리하고 소관 과를 배분한다. 현업 담당은 자기 과 문항에 회신하며, 총괄 담당은 회신을 취합·검사해 확정 대상을 정한다. 교육용 접수대장은 520건·15개 항목이며, 위원회 5개, 요구의원 20명, 조직도상 배분과 26개다. 요구유형은 자료요구 343건·서면질의 177건, 배분구분은 소관 450건·공통 70건, 제출형식은 엑셀 250건·한글 146건·PDF 124건이다. |
| ② 문제 | 요구서의 여러 문항을 사람이 나누고 배분하므로 시간이 들고, 여러 과가 관련되거나 기준표에 맞는 키워드가 없을 때 판단이 달라진다. 지침·메일·인수인계 내용이 흩어져 최신 기준 확인이 어렵고, 재배정·보완·확인 사유를 남기지 않으면 이력이 끊긴다. 기간 역전, 제출기한 이상, 조직도 밖 부서명, 중복 접수, 공란, 상태값 공백 등도 사람마다 확인 수준이 다르다. 기준표의 우선순위만 적용한 시험 결과는 26/40(65%)로 목표에 미달했다. |
| ③ 목표 | 문항별 소관 과 후보와 근거를 제시하고 최종 배분은 사람이 확정한다. 시험 40건에서 1순위 배분과 정확도 75% 이상을 달성한다. 검증용 120건에 포함된 의도된 오류 10건을 모두 찾아 확인 대상으로 표시한다. 520건과 15개 항목, 접수번호 520개를 보존하고 조직도 26개 과 밖의 부서를 자동 확정하지 않는다. |
| ④ 범위 | **만들 것:** 접수대장 읽기, 문항 상태 생성, 후보 3순위와 근거 제시, 총괄 배분 확정, 현업 회신·재배정요청, 총괄 보완요청·확정, 누락·이상 검사, 처리 이력. **만들지 않을 것:** 답변 문장 자동 작성, 결재, 국회 제출, 실제 기관 시스템 등록, 회사 20GB 자료 색인. **사람 판단:** 최종 배분, 주관·협조 과, 사실관계, 개인정보, 보완·확정 여부. |
| ⑤ 검증 기준 | 시험 40건 1순위 정확도 75% 이상, 시험의 공통 문항 6건 중 공통 표시 6/6, 검증용 120건의 의도된 오류 10건 검출, 회신 엑셀 샘플의 의도된 오류 3건 검출, 520행·15개 항목 보존, 접수번호 520개 보존, 조직도 밖 후보 자동 확정 0건, 확인 표시가 남은 문항의 확정 0건을 PoC 통과 기준으로 한다. 내부 시험의 40/40 결과는 같은 문장 패턴에 맞춰졌을 가능성이 있으므로 운영 정확도로 표현하지 않는다. 실제 회사 문항 검증은 `02_company_scale`의 C-12에서 별도로 수행한다. |

## 확인된 기준 숫자

| 항목 | 값 |
|---|---:|
| 접수대장 | 520건 / 15개 항목 |
| 접수번호 | 520개 |
| 조직도 | 26개 과 |
| 배분기준표 | 304건(소관 292 / 공통 12) |
| 시험 문항 | 40건(소관 34 / 공통 6) |
| 검증용 접수대장 | 120건(의도된 오류 10건) |
| 처리상태 | 제출완료 412 / 보완요청 53 / 기한연장 55 |

## 배분 추천 원칙

- 업무 지침 자체를 바꾸지 않는다.
- 주제어 위치, 기준표 키워드, 제외어, 조직도 주요업무, 공통 문항 여부를 **추천 점수 산식**에 반영한다.
- `예산`, `집행`, `언론`, `보도`처럼 여러 문항에 붙는 일반어는 구체적인 주제어가 함께 있을 때 감점한다.
- 기준표 우선순위는 추천 점수가 같은 후보를 정렬할 때 사용한다.
- 추천 결과에는 적용 키워드와 근거를 함께 표시하며 최종 배분은 국회 총괄 담당이 한다.

## 핵심 판단

PoC의 목적은 교육용 자료에서 업무 흐름과 자동 점검 가능성을 증명하는 것이다. 시험 40건과 검증용 120건, 회신 엑셀 샘플로 PoC를 판정한다. 회사용 대용량 자료의 저장·색인·보안 운영과 실제 회사 문항 정확도는 이 버전에 넣지 않고 `02_company_scale`에서 별도로 다룬다.
