# 문제정의서 (5칸)

| 칸 | 내용 |
|---|---|
| ① 현재 업무 | A부 국회 업무 담당자는 2026년 국정감사 요구자료 접수대장 520건을 기준으로 접수번호, 접수일, 국회구분, 위원회, 요구의원, 요구유형, 문항번호, 요구내용, 요구기간, 제출기한, 제출형식, 배분구분, 배분과, 처리상태 등 15개 항목을 관리한다. 업무 흐름은 요구서 접수 → 문항 단위 대장 등록 → 배분기준표와 조직도 확인 → 소관 과 배분 → 회신 취합 → 누락·오류 검증 → 결재 후 제출·기록 순서다. 2026년 접수대장에는 접수번호 520개, 위원회 5개, 요구의원 20명, 배분과 26개가 있으며, 요구유형은 자료요구 343건과 서면질의 177건, 배분구분은 소관 450건과 공통 70건, 제출형식은 엑셀 250건·한글 146건·PDF 124건이다. |
| ② 문제 | 문항 단위로 배분해야 하고, 한 문항이 여러 과에 걸치거나 기준표 키워드가 없을 때 담당자 판단이 달라질 수 있다. 지침재료가 인수인계서, 대응계획 메모, 업무메일, 구두지시로 흩어져 있어 최신 기준을 찾는 데 시간이 걸린다. 예를 들어 금액 단위는 2025-09-01 메모의 백만원 기준보다 2025-09-15 메일의 천원 기준이 최신이다. 배분 이견, 재배분, 확인필요 처리 이력을 남기지 않으면 후임자가 왜 그렇게 처리했는지 알기 어렵다. 또한 요구기간 연도 누락, 기간 역전, 조직도에 없는 부서명, 중복 접수, 제출기한 이상, 합계 불일치 같은 검증 항목은 사람마다 확인 수준이 달라 오류가 남을 수 있다. |
| ③ 목표 | 520건 접수대장의 15개 항목을 대상으로 문항별 소관 과 후보와 확인필요 사유를 자동으로 제시한다. 배분 후보는 조직도에 있는 26개 배분과 안에서만 제시하고, 공통 문항 70건은 주관 과와 협조 과 구분이 필요하다는 표시를 남긴다. 목표 정확도는 사용자 조건에 따라 시험 40건에서 1순위 배분과 정확도 75% 이상으로 둔다. 접수대장 검증은 빈 배분과 0건, 빈 처리상태 0건처럼 확인 가능한 항목부터 자동 점검하고, 담당자가 최종 판단해야 하는 항목은 확인필요로 분리한다. |
| ④ 범위 | 만들 것: 요구내용 문항 읽기, 배분기준표·조직도 기반 소관 과 후보 추천, 공통/소관 구분 보조, 확인필요 사유 표시, 접수대장 누락·이상 항목 점검, 처리 이력 기록 항목 설계. 만들지 않을 것: 답변 내용 작성, 국장 또는 과장 결재, 국회 제출, 제출 후 수정 제출 처리, 내부 시스템 실제 등록. 사람이 판단할 부분: 최종 배분과 확정, 여러 과가 걸친 문항의 주관·협조 결정, 개인정보 포함 여부와 마스킹 필요성, 의원실 확인이 필요한 날짜·기한 이상, 결재 이후 제출 여부. |
| ⑤ 검증 기준 | 시험 40건을 기준으로 1순위 배분과 정확도가 75% 이상이면 통과로 본다. 2026년 접수대장 520건을 읽어 행 수 520건과 15개 항목을 유지해야 하며, 접수번호 520개가 중복 없이 보존되어야 한다. 배분 후보는 조직도 기준 26개 배분과 밖의 부서명을 만들지 않아야 한다. 배분과가 비거나 기준표 매칭이 없거나 우선순위 동률인 문항은 임의 확정하지 않고 확인필요로 표시해야 한다. 답변·결재·제출 결과는 이번 검증 기준에 포함하지 않는다. |
